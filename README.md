# NotebookLM 簡報轉可編輯 PPTX 工作台 (NotebookLM to PPT)

將 NotebookLM 匯出的靜態簡報（PDF、圖片型 PPTX 或 PNG / JPG 圖片），透過瀏覽器端的「局部無痕筆畫抹除 + 原位疊加可編輯文字框」技術，一鍵轉換為可於 Microsoft PowerPoint 自由編輯文字的 `.pptx` 簡報檔案。

* **線上立即使用（GitHub Pages）**：[https://royechuang-tw.github.io/notebooklm-to-ppt/](https://royechuang-tw.github.io/notebooklm-to-ppt/)
* **線上圖文教學指南**：[https://royechuang-tw.github.io/notebooklm-to-ppt/tutorial.html](https://royechuang-tw.github.io/notebooklm-to-ppt/tutorial.html)

---

## 一、 核心特色

1. **滑鼠自由圈選局部無痕去字**：
   * 直接在投影片畫布上按住滑鼠左鍵框選想修改的標題、段落或數據，系統於 1 秒內自動抹除原字、辨識文字內容與顏色，並在原位建立可編輯文字方塊。
   * 未圈選的複雜資訊圖表（Infographics）、圓餅圖與視覺插畫維持 100% 原始高解析度畫質，不會因全頁重排而變形。
2. **智慧混合筆畫擴散修復（Inpainting）**：
   * 內建「筆畫遮罩 + 14 次鄰域調和擴散修復」演算法，僅針對文字筆畫像素進行周圍背景融合，不破壞漸層底圖、不留異色矩形色塊。
3. **自動無痕消除 NotebookLM 浮水印**：
   * 匯入 16:9 寬螢幕簡報時，預設自動無痕融合消除每頁右下角的 `NotebookLM` 浮水印，並可隨時勾選切換或無損還原。
4. **動態自適應多重長寬比**：
   * 自動偵測每頁投影片原始尺寸，原生支援 `16:9`（10 × 5.625 吋）、`4:3`（10 × 7.5 吋）、`16:10`（10 × 6.25 吋）、`A4 橫式 / 直式`、`1:1`、`9:16` 與自訂比例，確保畫布預覽字級（pt）與匯出後的 PowerPoint 母片比例完全一致。
5. **100% 純前端本機運算與資安防護**：
   * 零後端伺服器依賴，所有 PDF 渲染、PPTX 解壓縮、Canvas 影像修復、Tesseract.js 離線 OCR 與 PPTX 封裝全程在您的瀏覽器記憶體內執行，簡報檔案絕不外傳。

## 二、 標準操作 4 步驟

### 步驟 1：匯入簡報檔案
1. 開啟 [線上工作台](https://royechuang-tw.github.io/notebooklm-to-ppt/) 或在本地雙擊開啟 `index.html`。
2. 點擊「選擇檔案」或將檔案拖曳至中央虛線框（支援 `.pdf`、`.pptx`、`.png`、`.jpg`、`.webp`、`.bmp`，單檔上限 150 MB、最多 150 頁）。
3. 匯入後左側清單會列出所有投影片縮圖，並自動完成右下角浮水印無痕消除。

### 步驟 2：滑鼠左鍵拖曳框選要修改的文字
1. 於左側清單點選欲編輯的投影片頁面。
2. 在中央畫布上對準想修改的文字區域，**按住滑鼠左鍵拖曳拉出藍色選取框**（框選時四周可保留少許背景邊距），放開滑鼠左鍵。
3. 系統會自動抹除該區原字、執行離線 OCR 辨識，並在原位置疊加可編輯文字框。

### 步驟 3：修改文字內容、樣式與微調位置
1. **直接輸入文字**：在右側「已圈選的文字框」清單中直接修改文字內容，中央畫布會即時同步更新。
2. **調整樣式**：可於右側卡片自由修改「字級 (pt)」、點擊色票修改「顏色」或切換「粗體」。
3. **拖曳微調與無損還原**：可在中央畫布直接拖曳藍色虛線框微調位置；若想取消修改，點擊右側卡片的「刪除（還原原圖）」，該區塊底圖將 100% 無損恢復。
4. **純擦除文字技巧**：若僅想抹除畫面上的多餘文字或雜訊而不放置新文字，只需框選該區域後將右側文字框內容清空留白即可。

### 步驟 4：一鍵匯出可編輯 PowerPoint (`.pptx`)
1. 點擊頂部工具列右側的綠色按鈕「匯出可編輯 PPTX」。
2. 瀏覽器將自動產生並下載 `NotebookLM_Editable_YYYY-MM-DD.pptx`。
3. 使用 Microsoft PowerPoint 開啟後，所有圈選區域皆為獨立的原生文字方塊（預設字型：微軟正黑體 `Microsoft JhengHei`）。

## 三、 工具列與檢視模式說明

| 功能項目 | 說明與適用情境 |
| :--- | :--- |
| **去字模式：智慧混合（預設推薦）** | 採用筆畫遮罩與鄰域調和擴散修復，僅融合文字筆畫像素，適合帶有漸層、陰影或紋理的簡報底圖。 |
| **去字模式：背景純色覆蓋** | 以框選區域上下邊界的雙線性漸層底色填滿矩形，適合純白或單一純色背景。 |
| **抹除右下角浮水印** | 預設針對 16:9 簡報開啟。取消勾選可立即將所有頁面右下角還原為原始狀態。 |
| **畫布檢視：圈選編輯預覽** | 預設工作模式，同時顯示無字乾淨底圖與可拖曳的文字方塊。 |
| **畫布檢視：僅檢視無字底圖** | 暫時隱藏所有疊加的文字方塊，方便檢查原圖筆畫與浮水印是否抹除乾淨。 |
| **畫布檢視：檢視原始圖片** | 隨時切換回匯入時的原始簡報畫面，進行排版位置與字體大小比對。 |
| **還原本頁原圖** | 一鍵清空當前頁面的所有文字框，將該頁恢復為最初匯入的原始圖片。 |
| **整頁自動辨識此頁 / 全部頁面** | 適合整頁皆為純文字段落的投影片，使用瀏覽器離線 OCR 自動掃描全頁文字區塊。 |

## 四、 本機離線執行方式

本專案為零建置依賴的純靜態網頁應用程式，除直接使用 GitHub Pages 線上版外，亦可離線部署於個人電腦或企業內部網路：

1. 下載本儲存庫檔案（或執行 `git clone https://github.com/royechuang-tw/notebooklm-to-ppt.git`）。
2. 直接以 Chrome、Edge 或 Safari 瀏覽器雙擊開啟 `index.html` 即可運作，無須安裝 Python、Node.js 或任何後端套件。

## 五、 資安與隱私保護架構

1. **零外部資料傳輸**：嚴格配置 `Content-Security-Policy (CSP)` 與 `form-action 'none'`，禁止向任何第三方分析或雲端 API 傳送使用者簡報資料。
2. **CDN 子資源完整性驗證（SRI）**：所有前端函式庫（`PDF.js v3.11.174`、`JSZip v3.10.1`、`PptxGenJS v3.12.0`、`Tesseract.js v5.1.1`）皆鎖定固定版本並強制檢驗 SHA-384 雜湊簽章。
3. **防點擊劫持與 XSS 防禦**：內建 Anti-Clickjacking 框架阻斷保護、`no-referrer` 隱私標頭與嚴格的 DOM / CSS 屬性消毒機制。
